# tilt_estimation

Platform-neutral (no ESP-IDF headers) whole-body state estimation for TILT mk.2.

- `CenterOfMass` — CoM in base frame B from the URDF mass model
  (`tilt_kinematics/include/tilt/kinematics/RobotModel.h`, generated by
  `model/tools/generate_robot_model.py`).
- `DcmEstimator` — CoM, CoM velocity and DCM `xi = c + c_dot / omega` in a gravity-aligned frame
  whose origin is the stance sole point (or the midpoint of both soles in double support).

## Inputs each control cycle

| Input | Source on the robot |
|---|---|
| leg joint angles (firmware order L roll/pitch/knee, R roll/pitch/knee) | servo read-back (preferred, `joint_lag_s = 0`) or commanded angles (`joint_lag_s ≈ 0.03`) |
| roll, pitch (rad) | `tilt_MPU6050` complementary filter |
| gyro x/y/z (rad/s, body frame) | `imu_read_raw` + `gyro_to_rad_s` |
| support (double / left / right) | gait state or foot contact sensors |

IMU signs: roll = rotation about +x (left side up = +), pitch = about +y (nose down = +).
Set `roll_sign`, `pitch_sign`, `gyro_sign[]` after checking the mounting on hardware.

## Velocity model

`c_dot = gyro × (c − pivot) + LPF(joint term)`. In single support the pivot moves to the foot edge
that is on the ground (foot roll in G decides which). The joint term is low-passed
(`joint_velocity_filter_s = 0.03`) because differentiating encoder readings amplifies their noise.

## Validation (simulation/dcm/estimator_check.py, FLASH stepping in place)

Lateral DCM error vs MuJoCo ground truth, single support, rms / max (mm):

| Joint input | Ideal IMU | IMU noise 0.3°, gyro 0.02 rad/s + 0.01 bias, 10 ms delay |
|---|---|---|
| servo read-back | 1.1 / 3.5 | 3.4 / 8.9 (encoder noise 0.1°) |
| commanded + lag model | 7.2 / 7.9 | 4.6 / 9.4 |

With commanded angles the CoM is biased by ~6–7 mm because the loaded stance hip roll deflects
~3° under the gravity torque. Read the servos back when the bus timing allows.
Sagittal (x) DCM error is larger (≈5 mm rms) and is not used by the lateral gait yet.
